# GooseRot — manifeste des assets

## Référence Desktop Goose v0.31

Aucun asset de Desktop Goose v0.31 n’est réutilisé ou redistribué. Le comportement général et les constantes publiées par son API de modding servent seulement de référence clean-room. L’oie GooseRot est rendue par du code original et le gag Bloc-notes utilise une banque de mots propre au projet.

Le dossier local de référence est exclu de Git et du build. Ses sons, mèmes, textes, GIF, DLL et exécutables ne doivent jamais être ajoutés à une release GooseRot.
